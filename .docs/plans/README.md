# Plans

Implementation plans for non-trivial tasks in this repo. One file per task, named `YYYY-MM-DD-<slug>.md`. Format and execution protocol are defined in `.docs/rules/plan-execution.md`. Plans carry `status`/`base` frontmatter and a checkbox-driven milestone body so any session can resume exactly where the last one stopped.

Note: this project's milestone work (M00-M14) is separately tracked in `DEVELOPMENT_BUILD_PLAN.md` in this same folder, which predates this bootstrap and remains authoritative for that scope. Use dated `.docs/plans/` files for work outside that ledger's milestones (small features, one-off fixes, exploratory tasks).
