# Provider marks

`openai.svg` and `claude.svg` are the OpenAI and Claude marks from
[Simple Icons](https://github.com/simple-icons/simple-icons), retrieved on 2026-09-08. The Simple Icons
collection is published under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), so the icon
files themselves carry no attribution requirement; this notice records their provenance anyway.

The marks remain the trademarks of their respective owners. UseNotch uses them only to identify which
service a reading belongs to. It is not affiliated with, endorsed by, or sponsored by OpenAI or
Anthropic.

`ProviderGlyphs.cs` embeds the path data from these files so the marks render without adding an SVG
dependency. Both files use a 24 by 24 view box; keep that if you replace them, and update the embedded
path data in the same change so the two cannot drift apart.
